# Money interpretation

Use Colombian small-business language.

Examples:

- "35 mil" means 35000.
- "35k" means 35000.
- "treinta y cinco mil" means 35000.
- A bare number like "35" can be ambiguous in a financial write.

Current limitation:

The current tools are read-only. Do not register money movements yet.

For future writes, if the amount is ambiguous, ask before writing.
